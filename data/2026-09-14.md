### [1] [Exact Bayesian Tracking of Dynamic Network Topologies](https://arxiv.org/abs/2609.11263)
*Victor M. Tenorio,Elvin Isufi,Geert Leus,Antonio G. Marques*

Main category: eess.SP

TL;DR: 本文提出一种基于节点信号观测的无权有向图精确贝叶斯跟踪器，通过网络状态全后验分布实现不确定性量化与预测；利用快速沃尔什-哈达玛变换将预测步计算复杂度从 O(4^k) 降至 O(k2^k)，并针对未知转移概率提出 EM 学习框架，在合成与六个真实数据集上取得优于基线方法的跟踪精度与拓扑变化恢复速度。


<details>
  <summary>Details</summary>
Motivation: 跟踪网络拓扑的时间演化在社会网络、流行病学和传感器系统等领域是基础性难题。既有方法难以给出完整后验分布，导致不确定性量化、预测与决策缺乏原理性支撑；同时精确贝叶斯推断在大规模图上计算代价高昂，且网络转移概率往往未知。

Method: 将无权有向图的网络动态建模为布尔超立方体上的马尔可夫过程，各边按翻转概率独立转移；基于节点信号观测构建精确贝叶斯跟踪器，输出每时刻网络状态的全后验分布；把预测步转化为二进卷积，借助快速沃尔什-哈达玛变换将复杂度由 O(4^k) 降至 O(k2^k)（k 为最大节点度）；当转移概率未知时，采用期望最大化框架从观测信号中学习参数。

Result: 在合成数据与六个真实数据集上的实验表明，该方法相较当前最优方法及经典基线具有更高的跟踪精度、从拓扑变化中更快的恢复能力，以及有意义的不确定性估计。

Conclusion: 该工作提供了一个可精确推断、计算高效且能自适应学习转移概率的网络拓扑演化跟踪框架，兼顾后验不确定性量化与实际性能，适用于多类时序网络场景。

Abstract: Tracking the temporal evolution of network topologies is a fundamental challenge in social networks, epidemiology, and sensor systems, among others. This paper develops an exact Bayesian tracker for unweighted, directed graphs using nodal signal observations. This framework yields the full posterior probability distribution over network states at each time step, naturally enabling uncertainty quantification, prediction, and principled decision-making. We model the network dynamics as a Markov process on the Boolean hypercube, where edges transition independently according to a flip probability. For efficient computation, we cast the prediction step as a dyadic convolution, and leverage the Fast Walsh-Hadamard Transform to reduce the computational cost from $\mathcal{O} (4^k)$ to $\mathcal{O} (k 2^k)$, where $k$ is the maximum node degree. When the network transition probabilities are unknown, we develop an Expectation-Maximization framework to learn them from the observed signals. Comprehensive experiments on synthetic and six real-world datasets validate the proposed method and demonstrate its superior tracking accuracy, faster recovery from topological changes, and meaningful uncertainty estimates compared to state-of-the-art and classical baselines.

### [2] [AoI-driven Anomaly Detection Framework for Communication Networks](https://arxiv.org/abs/2609.11432)
*Zia Ul Islam Nasir,Alper Kose,Berna Ozbek*

Main category: eess.SP

TL;DR: 本文提出以信息年龄（AoI）作为时序异常指示器，结合基于估计峰值AoI（ePAoI）的特征选择与多种机器学习模型构建通信网络异常检测框架，实验表明该方法在提升检测性能的同时显著降低计算复杂度。


<details>
  <summary>Details</summary>
Motivation: 通信网络异常检测在时敏环境中仍具挑战性，过时信息会影响系统可靠性；AoI 虽已被广泛用于网络性能优化，但其在异常检测中的适用性尚未被探索。

Method: 提出基于 AoI 的异常检测框架，将 AoI 作为识别网络异常行为的时间指标；具体采用基于 ePAoI（估计峰值信息年龄）的特征选择技术，并与多种机器学习模型集成，作为补充性异常判定指标。

Result: 评估结果表明，基于 ePAoI 的特征选择不仅提升了异常检测框架的性能，还显著降低了计算复杂度。

Conclusion: AoI（尤其是 ePAoI）可作为通信网络异常检测的有效补充指标，兼顾检测性能提升与计算开销削减，拓展了 AoI 在异常检测领域的应用。

Abstract: Anomaly detection in communication networks remains a challenge, particularly in time-sensitive environments where stale information can affect system reliability. In this work, we propose an anomaly detection framework that leverages Age of Information (AoI) as a temporal indicator for identifying abnormal network behaviors. The AoI has been studied for network performance optimization, however, its applicability to anomaly detection remains unexplored. The proposed framework integrates a feature selection technique based on the estimated Peak Age of Information (ePAoI) with multiple machine learning models for communication networks as a complementary indicator. The evaluation results demonstrate that ePAoI-based feature selection enhances the performance of the anomaly detection framework while significantly reducing the computational complexity.

### [3] [terms.txt: A Consent and Compensation Protocol for Agentic Web Access](https://arxiv.org/abs/2609.11152)
*Rajarshi Chowdhury*

Main category: cs.NI

TL;DR: 提出 terms.txt 规范及基于 Web Bot Auth 签名的来源端强制交换协议，为机器访问提供可表达身份、目的、条款与价格的细粒度授权机制。


<details>
  <summary>Details</summary>
Motivation: 开放网络原本依赖"网站允许爬虫、搜索引擎回馈访客"的隐性契约，但公共测量显示该契约在 AI 爬虫与代理冲击下已破裂：自动化客户端占请求多数，训练类抓取占比最高，大型 AI 平台每回馈一位访客便抓取数千页面。现有 robots.txt 无法表达身份、目的、条款或价格，且易被绕过；新兴替代方案多为专有 CDN 功能，缺乏开放标准。

Method: 设计 robots.txt 风格的 terms.txt 文件，支持按路径、按用途声明机器访问条款；并构建来源端强制执行的交换机制，融合 Web Bot Auth 签名、签名意图（signed intent）、委托令牌、HTTP 402 协商与签名收据（signed receipts）。同时明确界定该交换可强制、可审计及留给合同约定的边界。实现为无依赖的轻量方案。

Result: 无依赖实现在单 vCPU 上为每个请求增加 0.20 至 0.65 ms 的开销，表明机制具备实际部署可行性。

Conclusion: terms.txt 与配套的签名交换协议为机器访问提供了开放、可表达的替代方案，在低开销下实现身份、目的、条款与价格的声明与验证，弥补 robots.txt 的能力缺口，形成对专有 CDN 方案的可替代路径。

Abstract: The open web ran on an unwritten bargain: sites admitted crawlers, and search engines sent visitors back. Public measurements show that bargain breaking under AI crawlers and agents. Automated clients now make up most requests, training dominates Cloudflare-classified crawling, and the largest AI platforms fetch thousands of pages for each visitor they return. The web's common control, robots.txt, cannot express identity, purpose, terms, or price, can be circumvented, and newer alternatives are largely proprietary CDN features. We specify terms.txt, a robots.txt-style file for per-path, per-purpose machine-access terms, plus an origin-enforced exchange using Web Bot Auth signatures, signed intent, delegation tokens, HTTP 402 negotiation, and signed receipts. We define what the exchange can enforce, audit, and leave to contract. A dependency-free implementation adds 0.20 to 0.65 ms per request on one vCPU.

</details>
